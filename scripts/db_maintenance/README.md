# DB Maintenance Scripts

Scripts for database recovery, verification, enrichment status, and BigQuery operations.

| Script | Purpose | Input | Output |
|---|---|---|---|
| `recover_churches.py` | Row-by-row recovery from corrupt SQLite DB. Drops indexes, copies salvageable rows, skips corrupt pages. Resumable via `churches_recovering.db`. | `churches.db.corrupt_20260615` | Clean `churches.db` |
| `merge_core_tables.py` | Copies non-churches tables from corrupt DB into recovering DB. Skips govt/ARDA tables (re-downloadable). | Corrupt DB + recovering DB | Merged recovering DB |
| `verify_and_swap.py` | Verifies integrity of recovering DB and swaps it in place of main DB. | `churches_recovering.db` | `churches.db` (replaced) |
| `audit_recovery_loss.py` | Compares corrupt backup vs recovered DB to report what denominations/sources/contacts were lost. | Corrupt + recovered DBs | Console report |
| `enrichment_status.py` | Query current DB for enrichment coverage: websites, emails, denoms, attendance, geo, analytic tables. | `churches.db` | Console report |
| `bq_export_to_sqlite.py` | Exports BigQuery `churches` table (342K rows, 298 cols) to local SQLite. Batch size 5K. Slow with ORDER BY. | BQ `American_Religious_Infrastructure.churches` | `churches.db` with BQ data |
| `bq_check_stats.py` | Quick BigQuery stats query: total rows, websites, emails, denom distribution. | BQ | Console report |

## Recovery Process (2026-06-15)

1. **`recover_churches.py`** — Recovered 183K/385K churches from corrupt DB (52% loss due to 4 corrupt B-tree pages at offsets 183K-385K)
2. **`merge_core_tables.py`** — Merged 7 core tables (church_sources, church_staff, org_links, org_officers, provenance_log, pss_schools, sources) with zero loss. Skipped 19 re-downloadable enrichment tables.
3. **`verify_and_swap.py`** — Finalized recovery: 183K churches, 303MB, integrity OK
4. **`bq_export_to_sqlite.py`** — Exported 342K clean churches from BigQuery (in progress)
